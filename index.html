Projects

My work

MOTOPHYLAX — IoT Smart Motorcycle Accident Detection System

Our capstone project: an Internet of Things-based system that detects motorcycle accidents and sends an emergency response. It is designed specifically for active Maxim motorcycle riders in Basak San Nicolas, Cebu City.

The system uses sensors to detect a crash, then automatically notifies emergency contacts so help can reach the rider faster. We identified the problem by looking at how long it takes for an accident to be reported in our area, and we designed MOTOPHYLAX so the alert happens without the rider needing to press anything.

Tools used: IoT sensors, microcontroller, and a mobile alert system.

BYTEQUEST — Educational Board Game

A digital board game we designed for our game development activity. The title is BYTEQUEST with the tagline "Answer Right, Move Forward." Players move along a numbered 100-square board from 1 to 100, and the game uses snakes and ladders that push you back or pull you forward. Every landing space is tied to a question the player must answer correctly before moving on.

My contribution: My contribution: I designed the board layout and decided where each snake and ladder would go so the game stayed balanced.

VLAN Network Design — Cisco Packet Tracer

A group networking activity where we built and configured a network in Cisco Packet Tracer. Our topology had three sites connected by routers — Main Router, Cebu Router, and Danao Router — with a switch on each side (SW-Main, Cebu-SW, Danao-SW) serving three workstations per site. We configured VLANs to separate network traffic, set static and DHCP addressing, and verified connectivity using the ping command in the command prompt.
